# 👻Fucking Tech!!!

下面给你一份可以直接执行的 **2天冲刺计划**（按小时拆分），是基于我对牛客网字节客户端三面面经的调研 + 你当前 ROSA 项目经历定制的。

先说结论：字节客户端三面的共性非常明确  
1. 项目深挖强于八股背诵（会追问设计取舍、性能、失败场景）。  
2. C++/OS/计网会连环追问到“原理层”。  
3. 常见手写是并发模型（生产者消费者/线程同步）+ 基础算法。
