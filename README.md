我在 Zotero 的“导航 > 图神经”分类里读到了 4 篇文献。先说明一下：这个分类里并不是 4 篇都属于“图神经网络论文”，而是两类混在一起：

1. **真正使用图神经/深度图学习的论文**：董林、赵书音。
2. **多 AUV 协同定位的传统图优化/滤波基线论文**：陈世杰、林家祺。

这反而很有用，因为它们可以组成一条完整研究链：**传统 EKF/因子图定位 → GNN/TGNN 学习定位误差与时序关系 → 联邦学习/节点筛选提升鲁棒性**。

**1.《基于动态图神经网络的复杂网络关键节点识别与研究》董林**
这篇不是机器人定位论文，而是复杂网络中的**关键节点识别**研究。它研究的问题是：在电力、交通、社交、通信等复杂网络中，哪些节点最关键，移除或激活这些节点会对整个网络产生最大影响。

主要工作有两条线：

第一，提出 **K-GCN**。它把传统复杂网络中的 **K-shell 分解**和 **GCN 图卷积网络**结合起来。作者认为，一个节点重要不重要，不只看它自己连接多少节点，还要看它邻居节点在网络核心层中的分布情况。因此先计算节点邻域的 K-shell 分布熵，再作为图神经网络的输入特征，让 GCN 学习节点重要性。

第二，提出 **MCTNDI 多属性决策关键节点识别方法**。它不是深度学习模型，而是把多个传统指标融合起来，例如接近中心性、介数中心性、H 指数、网络约束系数、局部邻域影响、路径中心性、互信息等，避免单一指标判断片面。

创新点主要是：

- 把 **邻域 K-shell 分布熵**引入 GCN，让 GCN 不只是学习连接关系，还学习节点在网络核心层中的结构位置。
- 用多属性决策方法融合多个中心性指标，解决“某个指标只适合某类网络”的问题。
- 实验不只看排序结果，还用 SIR 传播模型、牵制控制、蓄意攻击、单调性等方式验证关键节点识别是否真的有效。

实验设计：

- 数据集使用多个真实网络，例如 Contiguous USA、Dolphins、USAir97、Tech-routers-rf 等。
- K-GCN 用 SIR 传播模型评估：把模型识别出的关键节点作为初始感染节点，观察传播速度和最终感染规模。文中提到 SIR 实验做了多次独立运行，例如 500 次统计。
- MCTNDI 用蓄意攻击实验评估：按不同方法识别出的节点顺序删除节点，看网络效率下降速度。下降越快，说明识别出的节点越关键。
- 还使用单调性、Kendall 相关性、牵制控制实验来验证排序稳定性和控制效果。

实验配置方面，论文文本中没有清楚给出 GPU/CPU/软件环境。它更偏复杂网络算法实验，不是大规模深度模型训练。

**2.《主从式多AUV系统协同定位算法研究》陈世杰**
这篇是多 AUV 协同定位的传统算法论文，不使用 GNN，但它非常适合当作你后续 GNN/TGNN 复现的物理模型和对比基线。

论文研究的是：在主从式多 AUV 系统中，主 AUV 位置更准，从 AUV 依靠自身航位推算和主 AUV 提供的水声测距/状态信息修正自己的位置。核心难点是水下不能直接使用 GNSS，水声通信又有延迟。

主要工作：

- 建立主从式多 AUV 协同定位模型。
- 使用 **EKF 扩展卡尔曼滤波**进行协同定位。
- 分析单主 AUV 与双主 AUV 场景的可观性，指出单主模式可观性较弱，对主 AUV 机动性要求高；双主 AUV 协同定位效果更好。
- 研究编队拓扑对定位精度的影响，得出主从 AUV 连线角度接近 90 度时定位效果更好。
- 针对水声传播延迟，提出 **DEKF 延迟 EKF**。
- 针对主 AUV 运动状态变化导致 DEKF 跟踪不准的问题，引入 **IMM-DEKF**，也就是交互式多模型延迟 EKF。

创新点：

- 把水声通信延迟显式纳入 EKF 协同定位过程。
- 区分主 AUV 状态通信延迟和测距信息延迟。
- 用 IMM 的 CV、CA、CTRV 三种运动模型去适配主 AUV 不同运动状态。
- 证明主 AUV 变速运动时，IMM-DEKF 比 DEKF 更稳定。

实验设计：

- 先做单主/双主 AUV 协同定位仿真，验证可观性对定位结果的影响。
- 再做编队拓扑实验，分析主从 AUV 相对角度对定位误差的影响。
- 再做水声延迟实验，对比理想无延迟 EKF、未处理延迟 EKF、处理延迟的 DEKF。
- 最后做 IMM-DEKF 对比实验：主 AUV 匀速时，IMM-DEKF 与 DEKF 精度接近；主 AUV 变速时，IMM-DEKF 明显优于 DEKF。

关键结果：

- 在主 AUV 运动状态改变的时间段内，IMM-DEKF 相比 DEKF，各 AUV 定位误差降低约 **20% 到 40%**。

实验配置方面，论文主要是仿真实验，没有明显报告 GPU 配置。因为它是 EKF/IMM 类算法，不依赖深度学习训练，普通 CPU 就可以复现。

**3.《动态环境下基于因子图的多AUV协同定位方法研究》林家祺**
这篇同样不是 GNN，而是 **因子图优化**方向的多 AUV 协同定位论文。它解决的问题比陈世杰那篇更进一步：动态海洋环境中不仅有水声通信问题，还有非高斯噪声、稀疏异常噪声、系统拓扑变化、主 AUV 不可靠、参考节点不足等问题。

主要工作分三部分：

第一，提出基于 **RPCA 鲁棒主成分分析**的协同定位方法。动态海洋环境中，测量数据会出现稀疏噪声和突变误差。RPCA 把原始测量矩阵分解为低秩有效信息和稀疏噪声，从而剔除异常干扰。随后又使用改进的 LOWESS 平滑方法抑制定位突变。

第二，提出基于因子图的 **主 AUV 节点筛选方法**。不是所有主 AUV 都适合给从 AUV 提供参考信息。作者使用 Sobol 敏感性分析，判断主 AUV 的速度误差、航向误差、位置 RMSE、主从测距等参数对从 AUV 定位结果的影响，然后设计节点筛选因子，把低可信主 AUV 排除。

第三，提出分布式因子图协同定位方法。当主 AUV 分布稀疏、参考信息不足时，部分从 AUV 也可以被选择为参考节点。作者先做系统可观性分析，再设计从 AUV 节点筛选因子，让合适的从 AUV 参与定位参考，提高大规模任务下的鲁棒性。

创新点：

- 把 RPCA 用于水下协同定位中的稀疏噪声分离。
- 用 LOWESS 平滑抑制突发定位误差。
- 用 Sobol 敏感性分析指导主 AUV 节点选择，而不是人工固定选择参考节点。
- 在因子图框架中处理动态拓扑，即 AUV 节点数量、分布、可靠性发生变化的情况。
- 进一步考虑主 AUV 稀疏时，让从 AUV 也参与参考定位。

实验设计：

- 使用仿真构造多 AUV 协同定位场景。
- 先比较因子图 FG 与 EKF，验证因子图比滤波方法更适合全局误差优化。
- 再加入稀疏噪声，比较原始方法与 RPCA/LOWESS 改进方法，评价抗噪声能力。
- 再设计动态拓扑实验，模拟部分主 AUV 信息不可靠或掉线，通过节点筛选因子剔除低可信参考节点。
- 最后在主 AUV 参考不足的大规模场景下，测试分布式从节点筛选策略。

评价指标：

- 定位误差 RMSE。
- 仿真处理时间。
- 定位过程稳定性。
- 动态拓扑/掉线/噪声条件下的鲁棒性。

实验配置：

- 文中能读到的配置是：**Intel Core i7-12700H CPU @ 2.30GHz，32GB 内存**。
- 没看到必须使用 GPU 的信息。这类因子图、RPCA、EKF 实验用 CPU 就可以完成。

**4.《基于图神经网络的水下协同定位方法研究》赵书音**
这篇是你目前最应该重点看的，因为它和你之前一直讨论的 **GNN + LSTM/TGNN + 多 AUV 协同定位**最直接相关。

论文研究的问题是：水下 AUV 协同定位数据具有异源、异构、不同采样频率等特点，例如位置、速度、航向、加速度、水声时延等。传统 EKF/因子图依赖模型假设，难以充分学习复杂关系。因此作者把多 AUV 协同定位数据构造成图结构，用 GNN 学习节点关系，再用 TGNN 学习时序特征，最后用联邦学习解决水下数据传输受限问题。

主要工作：

第一，提出 **GNN 水下协同定位算法**。把每个 AUV 的状态信息、主从 AUV 的关系、水声时延等构造成图数据。GNN 负责学习 AUV 节点之间的信息关联，用于预测 AUV 的二维位置。

第二，提出 **TGNN 水下协同定位算法**。GNN 只能处理当前图结构，对时间连续性利用不足，所以作者在 GNN 后面结合 LSTM，形成时序图神经网络，让模型同时学习图结构特征和轨迹时间特征。

第三，提出 **FL-TGNN 联邦时序图神经网络算法**。水下通信带宽低，直接传输所有原始数据不现实，因此让各从 AUV 本地训练 TGNN 模型，主 AUV 只聚合模型参数，避免直接传输全部原始数据。

创新点：

- 把 AUV 协同定位问题转化为图学习问题。
- 用 GNN 融合异源异构传感器信息。
- 用 LSTM/TGNN 引入时序记忆，解决轨迹预测中的时间连续性问题。
- 用联邦学习处理水声通信受限场景，只传模型参数，不传全部原始数据。
- 与 EKF、FG、GNN、TGNN、Uni-TGNN 做了比较，实验链条比较完整。

实验设计：

- 数据集包含 **4 个 AUV，5001 个连续时刻**。
- 输入特征包括：平面位置 `(x, y)`、平面速度 `vs`、航向角 `θ`、平面加速度 `a`、与主 AUV 的水声传输时延 `delay`。
- 标签是真实位置，也就是让网络学习“带噪声、带时延、带多源信息的状态”到“真实轨迹位置”的映射。
- 数据集按 **80% 训练集、20% 测试集**划分。
- GNN 对比 EKF、FG。
- TGNN 对比 EKF、FG、GNN。
- FL-TGNN 对比 EKF、FG、GNN、TGNN、Uni-TGNN。

关键参数：

- GNN：`input_dim=6`，`output_dim=2`，隐藏单元 128，dropout 0.02，epoch 300。
- TGNN：`input_dim=6`，`window_size=20`，batch size 128，隐藏单元 128，dropout 0.2，`output_dim=2`，epoch 300。
- FL-TGNN：沿用 TGNN 结构，并进行联邦聚合。

核心实验结果：

| 方法 | AUV1 | AUV2 | AUV3 | AUV4 |
|---|---:|---:|---:|---:|
| EKF | 30.9665 | 25.8928 | 24.1810 | 14.9603 |
| FG | 23.1199 | 15.7371 | 19.3524 | 13.9345 |
| GNN | 15.3013 | 13.7599 | 10.5059 | 10.3783 |
| TGNN | 11.1569 | 10.1976 | 7.6754 | 5.8416 |
| FL-TGNN | 3.7921 | 4.2776 | 4.8629 | 3.2186 |

可以看到，实验逻辑很清楚：  
**EKF/FG 是传统基线，GNN 学图结构，TGNN 加入时间记忆，FL-TGNN 进一步融合多 AUV 模型信息，所以误差逐步下降。**

**算法出现时间**
这里先说明一下：`ST` 和 `TD` 不是单个算法，而是一类方法。`ST` 通常指 Subspace Tracking，`TD` 通常指 Tensor Decomposition。

| 类别 | 代表算法/思想 | 大致出现时间 | 说明 |
|---|---:|---:|---|
| NMF | Positive Matrix Factorization / Non-negative Matrix Factorization | 1994 / 1999 | Paatero 和 Tapper 1994 提出 PMF；Lee 和 Seung 1999 的 Nature 论文让 NMF 广泛流行。 |
| TD | CP/Tucker 张量分解 | 1927 / 1966 | CP 思想可追溯到 Hitchcock 1927；Tucker 分解来自 Tucker 1966；现代鲁棒张量分解用于背景分离主要在 2010 年后活跃。 |
| ST | 子空间跟踪 | 1982 / 1995 | Oja 在线 PCA 思想 1982；PAST 子空间跟踪 1995；鲁棒在线子空间跟踪后来发展出 GRASTA。 |
| MC | Matrix Completion 矩阵补全 | 2008 / 2009 | Candès 和 Recht 的精确矩阵补全 2008 arXiv、2009 期刊版本是代表性起点。 |
| RPCA | Robust PCA / PCP | 2009 / 2011 | Candès 等人的 RPCA 2009 预印本，2011 JACM 正式发表，是低秩+稀疏分解的经典工作。 |
| LRR | Low-Rank Representation | 2010 | Liu、Lin、Yu 在 ICML 2010 提出 LRR，用于鲁棒子空间分割。 |
| GRASTA | Grassmannian Robust Adaptive Subspace Tracking | 2011 / 2012 | 2011 arXiv，2012 CVPR，用于在线低秩子空间跟踪和前景/背景分离。 |

资料来源包括 GRASTA 的 CVPR 2012 论文介绍、RPCA 2011 JACM、MC 2009、LRR ICML 2010、NMF Nature 1999、张量分解综述等：  
[GRASTA CVPR 2012](https://mlanthology.org/cvpr/2012/he2012cvpr-incremental/)、[GRASTA arXiv 2011](https://arxiv.org/abs/1109.3827)、[RPCA arXiv/JACM](https://arxiv.org/abs/0905.0233)、[Matrix Completion 2009](https://authors.library.caltech.edu/17081)、[LRR ICML 2010](https://icml.cc/Conferences/2010/papers/521.pdf)、[NMF Nature 1999](https://www.nature.com/articles/44565)、[Kolda & Bader Tensor Decompositions 2009](https://www.kolda.net/publication/koba09/)。

**为什么 GRASTA 值得作为你的主算法**
林家祺《动态环境下基于因子图的多AUV协同定位方法研究》里，核心问题是：

1. 动态海洋环境会产生非高斯噪声、稀疏异常噪声。
2. 多 AUV 系统拓扑会变化，比如主 AUV 掉线、参考节点质量变差。
3. 传感器和水声通信信息可能不完整、不稳定。
4. 这些异常观测会进入因子图，导致定位 RMSE 增大。

林家祺用的是 **RPCA + LOWESS + 因子图 + 节点筛选**。你的思路可以进一步改成：

```text
传感器/测距/局部地图观测
        ↓
GRASTA 在线分离低秩背景 L 和稀疏动态项 S
        ↓
L 用于因子图定位 / 地图更新
S 用于异常观测剔除 / 动态障碍物代价层
        ↓
定位 + 避障 + 路径规划
```

也就是说，GRASTA 不只是替代 RPCA，它更适合解决“数据是连续流、观测不完整、动态变化快”的问题。

**基线实验怎么设计**
我建议你设计三层实验，这样最容易凸显 GRASTA 的优势。

**第一层：纯分离实验**
目的：只比较不同算法对动态项 `S` 的提取能力。

输入可以是：

```text
连续激光雷达 scan
连续局部 occupancy grid
AUV 测距/速度/航向/时延序列
```

构造成矩阵：

```text
D = L + S + N
```

其中：

- `L`：静态环境或稳定观测。
- `S`：动态障碍物、异常测距、主 AUV 掉线造成的突变。
- `N`：普通噪声。

对比算法：

| 方法 | 作用 | 你希望证明的问题 |
|---|---|---|
| RPCA | 经典低秩+稀疏分解 | 精度可以，但批处理慢，实时性弱 |
| ST/PAST | 普通子空间跟踪 | 在线快，但容易被异常点污染 |
| MC | 处理缺失观测 | 缺失数据下有效，但不专门处理稀疏异常 |
| LRR | 低秩表示 | 分离能力强，但计算重，实时性差 |
| NMF | 非负矩阵分解 | 可解释，但不适合负残差和突发异常 |
| TD | 张量分解 | 能利用时空结构，但计算复杂 |
| GRASTA | 在线鲁棒子空间跟踪 | 兼顾实时、缺失观测、稀疏异常 |

评价指标：

```text
动态项 S 的 Precision / Recall / F1
动态障碍物 mask 的 IoU
低秩背景 L 的重构误差
每帧处理时间
内存占用
是否支持在线更新
```

这一层最关键的是加入 **缺失观测率**：

```text
0%, 20%, 40%, 60% 缺失
```

因为 GRASTA 原论文强调它能从 partial information 中在线跟踪子空间，这正是它区别于普通 RPCA 的优势。

**第二层：定位实验**
目的：证明 GRASTA 分离出来的干净观测能提升因子图定位。

可以参考林家祺论文，把动态环境下的 AUV 协同定位分成几组：

| 实验组 | 动态分离方法 | 定位方法 |
|---|---|---|
| Baseline 1 | 不做分离 | 因子图 FG |
| Baseline 2 | RPCA + LOWESS | 因子图 FG |
| Baseline 3 | MC | 因子图 FG |
| Baseline 4 | LRR | 因子图 FG |
| Baseline 5 | TD | 因子图 FG |
| Ours | GRASTA | 因子图 FG |

GRASTA 的输出这样用：

```text
低秩部分 L → 作为较可信的测距/状态观测输入因子图
稀疏部分 S → 判断异常观测，对对应因子降权或剔除
```

也可以设计权重：

```text
w_i = exp(-alpha * |S_i|)
```

`S_i` 越大，说明该观测越像异常值，对应因子图中的测量因子权重越低。

定位评价指标：

```text
定位 RMSE
ATE 轨迹误差
最大定位误差
因子图优化收敛时间
异常噪声下的误差增长率
主 AUV 掉线时的鲁棒性
```

实验变量建议这样设：

```text
稀疏异常噪声比例：5%, 10%, 20%, 30%
通信缺失率：10%, 30%, 50%
动态障碍物数量：1, 3, 5
主 AUV 失效节点数：0, 1, 2
```

如果 GRASTA 表现好，你应该能看到：

- RPCA 精度可能不错，但处理时间更长。
- ST 很快，但异常噪声比例高时 RMSE 上升明显。
- MC 在缺失数据下有用，但遇到异常动态项时分离不够干净。
- LRR/TD 可能精度不错，但计算量大。
- GRASTA 在 RMSE 和实时性之间最好。

**第三层：导航闭环实验**
目的：证明 GRASTA 不只是“分离得好”，而是最终让机器人走得更安全。

流程：

```text
GNN/TGNN 定位
        ↓
GRASTA 分离动态障碍物 / 异常观测
        ↓
更新 local costmap
        ↓
路径规划器避障
```

对比组：

| 实验组 | 定位 | 动态分离 | 规划 |
|---|---|---|---|
| A | EKF / Odom | 无 | Nav2 |
| B | GNN/TGNN | 无 | Nav2 |
| C | GNN/TGNN | RPCA | Nav2 |
| D | GNN/TGNN | LRR/TD | Nav2 |
| Ours | GNN/TGNN | GRASTA | Nav2 |

导航评价指标：

```text
到达成功率
碰撞次数
最小障碍物距离
路径长度
通行时间
重规划次数
局部规划失败次数
平均处理延迟
CPU 占用
```

这里最能体现 GRASTA 的指标是：

```text
平均处理延迟
动态障碍物突然出现时的反应时间
高缺失观测下的成功率
长时间运行是否稳定
```

**你可以怎样凸显 GRASTA 的优秀**
不要只说“GRASTA 精度最高”，因为它不一定在所有离线场景都比 RPCA、TD 更准。更合理的论文表述是：

> 相较于传统 RPCA、LRR 和 TD 等批处理低秩分解方法，GRASTA 能够在流式观测条件下在线更新低秩子空间；相较于普通 ST 方法，GRASTA 使用鲁棒 L1 损失并能处理稀疏异常；相较于 MC 方法，GRASTA 同时考虑缺失观测与异常干扰。因此在动态障碍物、通信缺失和非高斯噪声共同存在的导航场景中，GRASTA 在实时性和鲁棒性之间取得更优平衡。

你的实验重点应该放在这四个场景：

1. **在线流式场景**：数据一帧一帧来，不能提前拿到全局矩阵。
2. **缺失观测场景**：模拟水声通信丢包、激光遮挡、局部地图空洞。
3. **稀疏异常场景**：模拟动态障碍物、异常测距、突然出现的干扰点。
4. **下游任务场景**：不仅比较分离结果，还比较定位 RMSE 和导航成功率。

这样设计后，你的结论会比较稳：

```text
RPCA 是经典强基线；
LRR/TD 是高精度重计算基线；
MC 是缺失观测基线；
ST 是在线速度基线；
NMF 是非负分解参考基线；
GRASTA 是兼具在线、鲁棒、缺失观测适应能力的主方法。
```

**最推荐你的实验标题**
你可以把这一部分设计成论文中的一个实验章节：

> 动态环境下不同低秩分离算法对机器人导航鲁棒性的影响分析

然后小节这样排：

1. 不同低秩分离算法的动态障碍物提取效果对比。
2. 不同缺失率下的分离鲁棒性实验。
3. 不同异常噪声比例下的定位 RMSE 对比。
4. GRASTA 辅助代价地图更新的导航闭环实验。
5. 实时性与计算复杂度分析。

这个设计很适合你现在的方向：它不是单纯炫算法，而是能说明 **GRASTA 为什么适合机器人动态导航场景**。
